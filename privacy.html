Privacy Policy

Oscar is a Discord bot that provides server administration, moderation, automoderation, protection, tickets, verification and community utilities. This policy explains what information Oscar may process when enabled in a Discord server.

Effective date: November 21, 2026 · Last updated: November 21, 2026

Information processed through Discord

  • Discord account and server identifiers, usernames, display names, role and channel identifiers, and membership events needed to run commands and server features.
  • Server configuration, moderation settings, warnings, cases, notes, role settings, ticket records, scheduled announcements, counters and related feature state.
  • Depending on enabled features and the permissions granted, message content and message metadata may be processed for automoderation, moderation logs, deleted/edited-message features, sniping, ticket conversations and transcript exports. Server administrators choose which logging and moderation features to enable.
  • Command interactions and feature activity needed to respond, enforce cooldowns, maintain counters or provide configured logs.

Optional web verification and IP information

  • Oscar's optional web verification flow can receive a visitor's IP address when the visitor opens the verification website. If web verification is enabled, Oscar may associate that IP address with the Discord account completing verification and store verification history, timestamps, user-agent details and related verification status.
  • An optional IP lookup feature can send an IP address to ip-api.com to obtain approximate location and network indicators such as country, city, ISP, proxy or hosting flags. This lookup is only used when the relevant IP lookup or VPN/proxy setting is enabled. ip-api.com processes the request under its own terms and privacy policy.
  • A Discord bot alone cannot see a member's IP address. IP collection described here occurs only through the optional web verification flow when it is configured and used.

How information is used

  • To operate commands and configured server features; protect servers against spam, raids and abuse; manage moderation cases and tickets; provide verification and anti-abuse checks; and maintain logs or transcripts requested by server administrators.
  • Oscar does not use this information to sell advertising or build advertising profiles.

Storage, access and retention

  • Bot data is stored in files on the machine or hosting service running Oscar. Access is generally limited to the bot operator and people with access to that host. Server administrators may also view information surfaced in their Discord server, configured log channels, ticket records or exported transcripts.
  • The project does not define one universal retention period for every category. Records may remain while needed for the configured feature or server administration. Server administrators and the bot operator are responsible for managing stored files, backups, logs and transcript archives.

Your choices and requests

  • You can contact the administrators of the Discord server where Oscar is used to ask about server-specific records, moderation logs or ticket transcripts. Server administrators can disable optional features, clear supported records or remove Oscar from their server.
  • For information held in the bot operator's hosting environment, contact the person or team operating that Oscar instance. Requests may need to be verified and may be limited by security, moderation or legal obligations.

Third parties and Discord

  • Oscar operates through Discord and is subject to Discord's own terms and privacy policy. Optional IP geolocation lookups may involve ip-api.com as described above. Hosting providers may process data to operate the server.

Security and changes

  • Reasonable technical measures are used in the project, but no internet-connected service or storage system can be guaranteed completely secure. The bot operator should protect access to hosting accounts, environment variables, backups and data files.
  • This policy may be updated when Oscar's features or data practices change. The effective date is shown at the top of this page.
